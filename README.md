# 🧭 AlgoViz

> This project is modified based on [AlgoViz](https://github.com/evelinvee/algoviz).
> Based on the original framework implemented by evelinvee.
> I added bidirectional BFS (双向广度优先搜索) visualization as my independent work.
> 
An interactive algorithm visualizer. Watch **pathfinding** algorithms (A*, Dijkstra, breadth-first) explore a grid you can draw walls on, and **sorting** algorithms (bubble, selection, insertion, quick, merge) rearrange a bar chart step by step. A small Python script generates the preset mazes; the rest runs entirely in the browser.

## ✨ Features

- **Pathfinding** — A\* (Manhattan heuristic), Dijkstra breadth-first search,bidirectional BFS and DFS on a grid
- **Draw your own maze** — click and drag to add walls, drag the start/target to move them
- **Preset mazes** — Comb, Rooms and Zigzag layouts (plus random walls) generated by Python
- **Sorting** — bubble, selection, insertion, quick and merge sort, animated with comparison/swap colours
- **Live stats** — cells visited & path length, or comparisons & swaps
- **Adjustable speed and array size**, fully responsive, no dependencies

## 🚀 My Improvements

Compared with the original project, I made the following improvements:

### 1. Bidirectional BFS

- Independently implemented bidirectional breadth-first search.
- Visualized the search process from both the start and end points.
- Implemented path reconstruction and verified path validity, endpoint correctness, and wall avoidance.

### 2. C++ and WebAssembly Migration

- Reimplemented the algorithm core in C++.
- Used Emscripten to compile C++ code into WebAssembly modules.
- Migrated pathfinding algorithms: BFS, DFS, Bidirectional BFS, Dijkstra and A*.
- Migrated sorting algorithms: Bubble Sort, Selection Sort, Insertion Sort, Quick Sort and Merge Sort.
- Used JavaScript to handle UI interaction, data transfer and animation playback.

### 3. Interaction Improvements

- Added exit controls for pathfinding and sorting visualizations.
- Improved the interface with Chinese labels and status messages.
- Improved the interaction between algorithm execution and visualization playback.

### 4. Testing and Debugging

- Tested algorithm outputs independently before integrating them into the visualization.
- Verified path validity, endpoint correctness and wall avoidance.
- Debugged communication between JavaScript and WebAssembly modules.

## ▶️ Run it

Regenerate the preset mazes (optional — `data.json` is committed):

```bash
python presets.py
```

Serve the folder and open it:

```bash
python -m http.server 8000
# http://localhost:8000
```

### Main Files

- `index.html` — Page structure and UI elements.
- `style.css` — Page styling and visual design.
- `app.js` — UI interaction, algorithm visualization and animation playback.
- `wasm-bridge.js` — Connects JavaScript with WebAssembly modules.
- `presets.py` — Generates preset mazes.
- `data.json` — Stores grid configuration and maze presets.

### WebAssembly Modules

- `wasm/bfs.cpp` — C++ implementation of BFS.
- `wasm/pathfinding.cpp` — C++ implementations of DFS, Bidirectional BFS, Dijkstra and A*.
- `wasm/sorting.cpp` — C++ implementations of sorting algorithms.
- `wasm/*.js` — JavaScript glue code generated by Emscripten.
- `wasm/*.wasm` — Compiled WebAssembly binaries.
```

## 🛠️ Tech

Python (standard library) · vanilla JavaScript · HTML · CSS. Search uses a shared best-first
frontier (BFS / Dijkstra / A\*); sorts are recorded as comparison/swap steps and replayed.
